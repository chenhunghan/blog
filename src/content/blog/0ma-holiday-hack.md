Holiday hack: I constrained myself to use only natural language to build software. Over the past few days, I have "vibe engineered" [0ma](https://github.com/chenhunghan/0ma), a lightweight Lima VM manager and simple K8s dashboard for local development.

This project taught me how to work effectively with coding agents. I started the design in AI Studio, then used a mix of agents like Claude Code (with GM 4.7), VS Code Copilot, and Antigravity.

The result is surprisingly good. At the end of 2025, LLMs are already excellent at design. There are still glitches here and there—I still had to review every line of code and be the "brain" when it struggled—but code agents are capable of producing code at a much higher quality than we could have imagined even 6 months ago.

No advanced prompting, no MCP, just working patiently with my LLM friends.
